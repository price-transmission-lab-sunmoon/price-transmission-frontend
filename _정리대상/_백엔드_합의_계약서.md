# 백엔드 합의 계약서 — price-transmission-frontend

> 프론트가 실제 호출하는 계약 표면 + **합의 필요 지점**. 상세 타입은 `src/types/`(literals·anomaly·timeseries·meta·commodity·event·error) 정본 참조. 스크래치(커밋 제외).

## 0. 공통
- **baseURL** = `VITE_API_BASE_URL` (기본 `http://localhost:39745/api/v1`). 모든 경로 = 이 prefix 이후. axios timeout 30s.
- **mock 토글**: `VITE_USE_MOCK !== 'false'` → fixture. dev=`.env.development.local`(true), build/prod=`.env`(false). vite proxy `/api`→39745.
- **에러 envelope(필수, 모든 4xx/5xx)**: `{ "error": { "code": string, "public_code"?: string, "message": string, "context"?: object } }`. `code`=내부, `public_code`=노출용(분리, BE-4). `error.code` 없으면 프론트 `PARSE-SCHEMA-001` 처리.
- **공인 public_code**(프론트 분기): `WHOLESALE_NOT_AVAILABLE`(422)·`INVALID_LAYOUT`(400)·`COMMODITY_NOT_FOUND`·`ANOMALY_NOT_FOUND`·`ML_MAP_NOT_READY`·`WARMUP_PERIOD_ONLY`(404)·`INVALID_SEGMENT`·`INVALID_GRANULARITY`·`INVALID_DATE_RANGE`·`INVALID_METRIC`·`SNAPSHOT_METRIC_ON_SERIES`(422)·`NOT_IMPLEMENTED`·`PIPELINE_DATA_MISSING`(5xx)·`UNTIL_EXCEEDS_TO`. 내부 code: `API-VAL-001`·`API-ANO-001`·`API-MET-001`·`API-MET-002`.
- **enum(literals.ts SSOT)**: ConfidenceGrade `high|medium|reference` · PrimaryPattern `pattern1|pattern2|pattern3` · Granularity `monthly|quarterly|yearly` · SegmentId `A|B|C|D|D_prime` · ModelType `VAR|VECM` · MlModel `isolation_forest|lof|ocsvm` · StatSeriesMetric `transmission_rate|zscore|ect|breakpoints` · StatSnapshotMetric `iqr|asymmetry` · RawPriceSource `intl_price_krw|import_price_usd|ppi|wholesale_price|cpi` · Cluster `grain|oil_sugar|tropical|livestock|independent` · RouteType `3seg|4seg` · ProjectionMethod `pca|feature_direct`.

## 3. ★합의 필요 지점 (우선순위)

### CRITICAL
- **C1. raw_prices fixture label_kr mojibake** — `raw_prices.json`·`raw_prices_minimap.json`의 `series[].label_kr` 전체 인코딩 손상(`'�?��가...'`). 백엔드 실응답 **`Content-Type: application/json; charset=utf-8` 보장** + 정확한 label_kr 합의(추정: intl_price_krw=`국제가(원화 환산)`, import_price_usd=`수입단가`). ※여정탭은 source→로컬매핑 우회 중이나 RawPricesChart 탭은 label_kr 직접 사용.

### HIGH
- **H1. transmission_rate 스케일** = **dimensionless ratio**(0.5=50%, ×100 금지, `services/anomaly.ts formatRatio`). 백엔드 퍼센트(50.0) 반환 시 전탭·여정 깨짐. → 비율로 통일.
- **H2. transmission_rate nullable 불일치** — `types/anomaly.ts` AnomalySummaryItem=`number`(non-null) vs `hooks/useAnomaliesSummary.ts`=`number|null`. 백엔드 null 여부 확정 → SoT 통일(UI는 |null이 안전).
- **H3. ml_summary percentile 스케일** — fixture=0~100(96.3 등), 여정 ④가 `/100` 가정. 0~1 vs 0~100 **명시 합의**(BE-5는 null 허용만 합의). 0~1이면 % 오표시.
- **H4. asymmetry model_type='TECM'** — `ModelType`(VAR|VECM) enum에 없음. 백엔드 실제값(TECM? VECM?) 확정 + literals 반영.
- **H5. IRF 응답에 anomaly_id 없음** — `/anomalies/{id}/irf`인데 응답 최상위 commodity_id·segment_id만. anomaly_id 반환 여부 합의.
- **H6. ml score/percentile null 조건** — warmup/결손 시 null(BE-5). 모델별 score·percentile 쌍 null 여부, warmup 정의·최소 포인트 수 문서화.

### MEDIUM
- **M1. /api/v1 prefix** — 백엔드 라우터 prefix `/api/v1` 서빙 합의. 배포 시 `VITE_API_BASE_URL` prefix 포함 여부 확정.
- **M2. anomaly_id = number(정수 PK)** — URL에 `/anomalies/{int}/` embed. 백엔드 PK가 UUID/string이면 계약 파괴. integer auto-increment 합의.
- **M3. stream from/to 미전송 → 전체 기간 반환 필수**(P2-4). 페이지네이션/기본기간제한 금지(아니면 미니맵·필터 확장 시 빈 화면).
- **M4. raw-prices layout 1~6 source 조합** — 번호별 포함 source 매핑 테이블 미문서화(fixture는 layout=2뿐). 합의 + `layout=1→transmission_overlay=[]`(null 금지).
- **M5. period 포맷** — yearly=`YYYY`, else `YYYY-MM`. minimap density=`YYYY`. 백엔드 `YYYY-01` 반환 시 D3 파싱 깨짐.
- **M6. /anomalies/summary 필터 파라미터**(month·grade 등) 지원 여부 — 현재 훅 무파라미터(최신 기준월 자동). 버저닝 시 명시.
- **M7. RawPriceAnomalyNode vs StreamAnomalyNode 차이**(raw엔 transmission_rate·pattern_types 없음) 의도 확인.

### LOW
- **L1. RocketFeatherDirection 'symmetric'** = 프론트 내부 전용. 백엔드는 `upward_stronger|downward_stronger|null`만 반환(symmetric 금지).
- **L2. ProjectionMethod 'feature_direct'**(OI-15 미결) — 지원 여부(pca만? 둘 다?) + x_label/y_label 확정.
- **L3. ScatterResponse.until(|null)** — null 발생 조건(데이터 없음/미지원) 합의.
- **L4. UNTIL_EXCEEDS_TO** — handleQueryError 분기 있으나 PERMANENT_FAILURE 미등록 → 무한 retry 위험. 백엔드 반환 여부 + 등록 합의.
- **L5. PipelineNode.phase_number 소수**(7.5) 허용 — 정렬/표시 정수 가정 금지.
- **L6. IrfCurve.subperiod_index** — scope=subperiod만 존재. full엔 생략.
- **L7. 파라미터 파싱** — layout=정수, from/to=`YYYY-MM`(월 경계 처리 정책).

## 5. 백엔드 회신(ed79246) 반영 결과 — FE 적용 완료
**코드 수정(적용·빌드 통과):**
- `error.ts` PERMANENT_FAILURE에 `UNTIL_EXCEEDS_TO` 추가(무한 retry 방지).
- `Minimap.tsx` yearly period 파싱 `%Y`→`%Y-%m`(백엔드 yearly=`YYYY-MM`·12월). minimap density period는 그대로 `YYYY`.
- `literals.ts` MODEL_TYPES += `TECM`·`asymmetric_VAR`.
- `anomaly.ts` AnomalySummaryItem.transmission_rate `number`→`number|null`.
- `RawPricesChart.tsx` SOURCE_LABEL → 백엔드 _SOURCE_META 正本(국제가 (원화 환산)·수입단가·생산자물가지수 (PPI)·소비자물가지수 (CPI)·도매가격).
- fixtures `raw_prices.json`·`raw_prices_minimap.json` label_kr mojibake → 正本 치환(UTF-8).

**이미 정합(수정 불요)**: public_code는 `error.code`에서 읽음(`?? body.code` 폴백 존재), WHOLESALE/SNAPSHOT 400은 FE가 publicCode로 분기(status 무관), ML 빈응답 `total_points===0` 처리됨, INVALID_LAYOUT+API-VAL-001 둘 다 PERMANENT, H1 ratio·H3 percentile 0~100(여정 /100)·H5 IRF anomaly_id 없음.

**계약 문구 정정**: M3 `/stream from/to` = 백엔드 **수신·처리함**(FE 미전송은 선택). "금지"는 오기였음.

**미적용(백엔드 후속 대기)**: /stream 캐시키 버그·anomaly_summary 스텁(total_count=0)·palmoil 표기·summary grade public_code(API-VAL-001) — 백엔드 수정 후 재확인.

**여정 영향 없음**: ④ percentile /100 = 정합 확인(H3). 여정 ① SOURCE_LABEL은 도식뷰라 간결 유지(RawPricesChart만 正本 mandate).
