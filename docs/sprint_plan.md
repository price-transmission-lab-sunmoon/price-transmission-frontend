```
main
└── dev
    ├── frame/backend
    ├── frame/frontend
    ├── feat/pipeline-phase2-3
    ├── feat/pipeline-phase4-5
    ├── feat/pipeline-phase6-7
    ├── feat/pipeline-phase7-ml
    ├── feat/pipeline-phase8
    ├── feat/api-endpoints
    ├── feat/db-connection
    ├── feat/batch-scheduler
    ├── feat/redis-cache
    ├── feat/stream-chart
    ├── feat/analysis-panel
    ├── feat/scatter-chart
    └── feat/raw-timeseries
```

**브랜치 3대 규칙**:
1. `frame/` dev 머지 전 `feat/` 브랜치 생성 금지
2. `feat/` 브랜치 생성 전 기능 명세 PM 승인 필수
3. `dev → main` 머지는 end-to-end 동작 확인 후에만
