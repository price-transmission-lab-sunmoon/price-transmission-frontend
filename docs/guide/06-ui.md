# 06 · UI 부품 (`UI-*`)

> `src/components/ui/` — 여러 화면에서 재사용하는 작은 시각 부품 9종.
> 대부분 Tailwind 클래스 조합 + variant/size 매핑 객체로 만든 단순 컴포넌트. `src/components/ui/index.ts`가 barrel export.

---

### UI-01 · Button
- 위치: `src/components/ui/Button.tsx`
- 무엇: variant(primary/secondary/ghost/danger) × size(sm/md/lg) 다형 버튼. leadingIcon·trailingIcon·fullWidth 지원. `forwardRef`. `BASE + SIZE_CLASS + VARIANT_CLASS` 클래스 조합.
- 왜: 버튼 스타일을 한 곳에서 통일.

### UI-02 · IconButton
- 위치: `src/components/ui/IconButton.tsx`
- 무엇: 텍스트 없는 아이콘 전용 버튼. variant(primary/outline/ghost). `aria-label` 필수(a11y). forwardRef.
- 왜: 필터/패널/헤더의 아이콘 버튼 통일.

### UI-03 · Icon
- 위치: `src/components/ui/Icon.tsx`
- 무엇: [[UTIL-07]] ICON_PATHS에서 path를 골라 인라인 SVG 렌더. 일부 아이콘(sparkles/play/pause/dot/bolt)은 기본 filled, 나머지는 stroke. 기본 `flexShrink:0`.
- 왜: 외부 아이콘 라이브러리 없이 SVG path만으로 아이콘 제공(brief 제약).

### UI-04 · Badge
- 위치: `src/components/ui/Badge.tsx`
- 무엇: 알약형 라벨. tone 8종(neutral/brand/success/warning/error/info/violet/teal-light) × size(sm/md). uppercase 옵션.
- 왜: 상태·분류 표시 통일. violet/teal-light는 방법론 패턴 카드 전용.

### UI-05 · ConfidenceBadge
- 위치: `src/components/ui/ConfidenceBadge.tsx`
- 무엇: 신뢰도 등급 전용 뱃지. high/medium/reference에 따라 배경·테두리·글자색을 [[UTIL-03]] ANOMALY_* 팔레트에서 가져옴. 라벨 = 고신뢰/중신뢰/참고.
- 왜: 등급 색을 차트 노드와 일치시켜 시각 일관성.
- 주의: 라벨 매핑이 [[SVC-03]] confidenceLabel과 동일(중복) — 표시 문자열은 동일.

### UI-06 · Switch
- 위치: `src/components/ui/Switch.tsx`
- 무엇: 트랙+노브 토글. label(before/after 위치), size(sm/md), disabled. `role="switch"`.
- 왜: FilterBar 구간 on/off 등에 사용.

### UI-07 · StateView
- 위치: `src/components/ui/StateView.tsx`
- 무엇: loading/empty/error/warning 상태 카드. size 3종(large/inline/chip). loading은 CSS 회전 스피너, 나머지는 아이콘 버블 + 제목 + 설명 + 에러코드 + 액션.
- 왜: 차트·패널의 로딩·빈·오류 화면을 한 컴포넌트로. always-mount 오버레이로 자주 쓰임([[CHART-01]] 등).

### UI-08 · Toast + showToast
- 위치: `src/components/ui/Toast.tsx`
- 무엇: 전역 알림. `showToast(payload)`가 `'fe:toast'` CustomEvent 발행 → `<Toast>` 컴포넌트가 수신해 표시. 큐 최대 4(FIFO), onRetry 없으면 동일 code 5초 throttle, 8초 자동 사라짐, 재시도 버튼.
- 왜: 컴포넌트 어디서든 import 없이 알림 발행(이벤트 버스 방식).
- 연결: [[API-09]] handleQueryError, [[API-12]], [[UI-09]]가 호출.

### UI-09 · ErrorBoundary
- 위치: `src/components/ui/ErrorBoundary.tsx`
- 무엇: React 클래스 에러 경계. 하위 트리 렌더 에러를 잡아 콘솔 로그([[API-11]] formatErrorChain) + [[UI-08]] Toast(FE-BOUNDARY-001) + fallback UI(새로고침 버튼, dev면 에러 상세).
- 왜: 한 컴포넌트 에러가 앱 전체를 흰 화면으로 만드는 걸 방지.
- 연결: [[LAYOUT-10]] App 최상위에 마운트.
